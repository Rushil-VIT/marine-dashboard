# 🌊 Marine Intelligence Dashboard

A high-precision, full-stack monitoring platform designed to track, analyze, and visualize **marine pollution and oil spill data** in real time.

This system integrates environmental datasets, analytics, and geospatial visualization to support **data-driven decision-making for ocean conservation and disaster response**.

---

# 🚀 Project Overview

Marine ecosystems are constantly threatened by oil spills and pollution. This platform provides:

- 📊 Real-time analytics of marine incidents  
- 🗺️ Interactive geospatial visualization  
- 📈 Data-driven cleanup prioritization  
- 📁 Dynamic pollution data upload system  

Built with a **modular full-stack architecture**, the system is responsive, scalable, and designed for real-world environmental applications.

---

# 🧠 Core Features

## 📍 Dashboard
- Overview of spills and pollution events  
- Dynamic stat cards  
- Integrated pollution + spill insights  
- Clean responsive grid layout  

---

## 🧪 Analytics Engine
- Severity distribution (Pie Chart)  
- Pollution type analysis (Bar Graph)  
- Cleanup prioritization:
  - Combines spill + pollution data  
  - Ranks based on severity and impact  

---

## 🌐 Interactive Map
- Built using Leaflet  
- Displays:
  - Oil spill locations  
  - Pollution hotspots  
  - Heatmaps  

---

## 📁 Pollution Data Upload System
- Upload `.json` (and optionally `.csv`) files  
- Automatic parsing and validation  
- Merges with existing dataset  
- Updates analytics instantly (no reload)  

---

## ⚙️ Settings & Customization
- Theme switching  
- UI personalization  
- Audio controls  

---

## 📱 Fully Responsive
- Works across:
  - Mobile  
  - Tablet  
  - Desktop  
- No layout breaks or overflow
